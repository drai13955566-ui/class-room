راهنمای راه‌اندازی پانتومیم شهید سلطانی

محتویات ZIP:
- pantomime_teacher.html : پنل کامل معلم؛ بازی، نمایش کلمه، زمان‌سنج، ثبت پاسخ و امتیازدهی
- pantomime_student.html : پنل دانش‌آموز؛ فقط نام گروه‌ها و امتیازها را نشان می‌دهد و هر ۱۰ ثانیه به‌روزرسانی می‌شود
- README-setup.txt : همین راهنما

راه‌اندازی اولیه (فقط یک‌بار):
1) هر دو فایل HTML را در ریشه مخزن GitHub با نام class-room بارگذاری کن.
2) مخزن باید Public باشد.
3) در Settings > Pages، گزینه Deploy from a branch را انتخاب کن، Branch را روی main و Folder را روی /(root) بگذار و Save را بزن.
4) در پنل معلم، بخش «تنظیم اتصال دانش‌آموزان (فقط یک‌بار)» را باز کن.
5) نام کاربری drai13955566-ui و نام مخزن class-room از قبل وارد شده‌اند. اگر نام مخزن واقعی متفاوت است، آن را اصلاح کن.
6) توکن Fine-grained GitHub را وارد کن؛ فقط همان مخزن را انتخاب کن و Repository permissions > Contents را روی Read and write بگذار.
7) «ثبت تنظیمات اتصال» را بزن. تنظیمات روی همان مرورگر/دستگاه معلم ذخیره می‌شود.

استفاده سر کلاس:
- بازی را از پنل معلم اجرا کن؛ کلمه فقط در پنل معلم نمایش داده می‌شود.
- گروه‌ها نوبتی بازی می‌کنند. زمان‌سنج، درست، رد کردن و خطا مانند قبل کار می‌کنند.
- هر زمان خواستی امتیازها را برای دانش‌آموزان منتشر کنی، فقط دکمه «ذخیره امتیازها برای پنل دانش‌آموزان» را بزن.
- پنل دانش‌آموزان بدون ورود و بدون نمایش کلمه، نام گروه‌ها و امتیازها را نمایش می‌دهد.

نکات مهم:
- نام مخزن در کد پنل دانش‌آموز روی class-room تنظیم شده است. اگر نام مخزن چیز دیگری است، مقدار GITHUB_REPO در pantomime_student.html را تغییر بده.
- توکن GitHub در حافظه محلی مرورگر دستگاه معلم ذخیره می‌شود تا هر بار وارد نشود. این کار راحت‌تر است اما امنیت کامل ایجاد نمی‌کند؛ دستگاه باید شخصی و محافظت‌شده باشد. هرگز فایل پنل معلم را در اختیار دانش‌آموزان نگذار.
- رمز و توکن در سمت مرورگر استفاده می‌شوند؛ این روش برای پروژه کلاسی ساده است و جایگزین بک‌اند امن با احراز هویت واقعی نیست.
- دانش‌آموزان فقط JSON عمومی را می‌خوانند؛ بنابراین مخزن و فایل داده باید عمومی باشند.
